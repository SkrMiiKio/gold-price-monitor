# gold-price-monitor (金价实时监控)

## 项目主页
[https://gitee.com/miikio/gold-price-monitor](https://gitee.com/miikio/gold-price-monitor)

## 项目简介
- 版本： 0.1.0
- 更新时间： 2025.11.20
- 定位：桌面程序、悬浮窗程序
- 介绍：简易的悬浮窗监控桌面程序，实时监控黄金价格的变化。

## 命令行使用示例
```bash
# 安装依赖
npm install

# 本地开发演示
npm run start

# 打包程序目录
npm run package

# 生成程序文件
npm run make
```
