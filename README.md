# gold-price-monitor (金价实时监控)

## 项目主页
[https://gitee.com/miikio/gold-price-monitor](https://gitee.com/miikio/gold-price-monitor)

## 项目简介
- 版本： 0.2.0
- 更新时间： 2026-04-11
- 定位：桌面程序、悬浮窗程序
- 介绍：简易的悬浮窗监控桌面程序，实时监控黄金价格的变化。接口基于京东金融平台，支持查看国际金价、美元指数、人民币汇率、各大银行积存金价格。

## 命令行使用示例
```bash
# 安装依赖
npm install

# 本地开发演示
npm run start

# 打包程序目录
npm run package

# 生成程序文件
npm run make
```
